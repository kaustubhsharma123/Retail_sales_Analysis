# 🛒 Retail Sales Analysis

## 📌 Overview
This project analyzes retail sales data to uncover insights into customer behavior, product performance, and sales trends.

## 🎯 Objective
To identify key drivers of sales and provide actionable business insights.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Analysis
- Sales by product category
- Gender-based purchasing behavior
- Age group analysis
- Sales trends over time
- Top customers

## 📈 Key Insights
- Clothing category has highest sales volume
- Electronics generate higher revenue
- Female customers slightly outspend male customers
- Age group 25–35 contributes most sales

## 📁 Project Structure
- data/ → dataset
- notebooks/ → analysis
- outputs/ → visualizations
